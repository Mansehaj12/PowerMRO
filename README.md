# PowerMRO

PowerMRO is a premium industrial dashboard for Maintenance, Repair & Overhaul management, designed specifically as a portfolio piece for Rolls-Royce Power Systems.

## Features
- Real-time Equipment Health Monitoring
- Automated Maintenance Scheduling
- Complete Repair History & Reporting
- Predictive Analytics for Remaining Useful Life (RUL)

## Tech Stack
- Next.js 14
- React
- Tailwind CSS
- Framer Motion
- Recharts
